Authorization Code Flow 테스트

1 Authorization 요청

아래 버튼을 클릭하면 인가 페이지로 이동합니다. 로그인 후 동의하면 redirect_uri로 authorization code가 전달됩니다.

PKCE 필수 클라이언트: code_challenge가 자동 생성되어 URL에 포함되었습니다. 토큰 교환 시 아래 code_verifier 값을 사용하세요.
code_verifier: verifier
authorization url
Authorization 요청 시작
2 Token 교환

Authorization code를 받은 후, 아래 curl 명령어로 access token을 요청합니다:

# Authorization Code를 Access Token으로 교환 curl -X POST http://localhost:9000/oauth2/token \ -H "Content-Type: application/x-www-form-urlencoded" \ -u "client_id:YOUR_CLIENT_SECRET" \ -d "grant_type=authorization_code" \ -d "code=AUTHORIZATION_CODE" \ -d "redirect_uri=redirect_uri" \ -d "code_verifier=code_verifier"
3 Token 응답 예시
{ "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...", "refresh_token": "abc123...", "token_type": "Bearer", "expires_in": 3600, "scope": "openid profile email", "id_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..." }
4 UserInfo 조회
# Access Token으로 사용자 정보 조회 curl -X GET http://localhost:9000/userinfo \ -H "Authorization: Bearer ACCESS_TOKEN"

Refresh Token 사용

# Refresh Token으로 새 Access Token 발급 curl -X POST http://localhost:9000/oauth2/token \ -H "Content-Type: application/x-www-form-urlencoded" \ -u "client_id:YOUR_CLIENT_SECRET" \ -d "grant_type=refresh_token" \ -d "refresh_token=REFRESH_TOKEN"

OIDC Discovery

OpenID Connect Discovery 문서를 조회합니다:

curl http://localhost:9000/.well-known/openid-configuration
